# LUNOR OS 1.1 — Part 4: Desktop wallpaper and base theme

Status: implemented.

## Wallpaper set

LUNOR OS 1.1 includes three desktop backgrounds:

- `lunor-wallpaper.png` — default Aurora/Fold composition.
- `lunor-horizon.png` — restrained horizon variation.
- `lunor-silence.png` — minimal near-black variation.

The default composition keeps its strongest visual element on the right side so the desktop remains calm and usable.

## Base color scheme

The KDE color scheme is installed as `Lunor.colors`.

Core identity:

- Midnight Black: `#02050A`
- Deep Navy: `#0A1324`
- Luminous White: `#F5F8FF`
- Aurora Blue: `#9EC9FF`

Aurora Blue is also the default Plasma accent color.

## Scope

This is intentionally a base theme only. Custom iconography, window decoration styling, animation tuning, panel redesign and launcher redesign are reserved for later versions.
