# LUNOR OS 1.1 — Part 1: Boot

Status: implemented.

## Visual direction

- Midnight Black `#02050A`
- Deep Navy `#0A1324`
- Luminous White `#F5F8FF`
- Aurora Blue `#9EC9FF`
- Clean, calm, futuristic, premium
- No RGB/gaming treatment

## Behaviour

1. Dark navy background with a restrained aurora halo.
2. LUNOR Fold mark fades in.
3. Logo has a subtle breathing glow.
4. Three-dot loading indicator pulses near the bottom.
5. Real boot messages may appear low on screen when Plymouth emits them.
6. Theme hands off to SDDM after boot; login design belongs to Part 2.

Theme path: `/usr/share/plymouth/themes/lunor/`.
