# LUNOR OS 1.1 — Part 5: System branding

Status: implemented.

## Identity

The operating system now reports itself consistently as:

- Name: **LUNOR OS**
- Version: **1.1**
- Codename: **Aurora**
- Edition: **Desktop**
- Base: Debian 13 (trixie)

## Updated identity surfaces

- `/etc/os-release`
- `/etc/lsb-release`
- `/etc/lunor-release`
- `/etc/issue`
- ISO application name, volume label and image name
- Installer desktop shortcut
- LUNOR application/distributor icon
- Project README and VERSION metadata

The system icon uses the LUNOR Fold mark and the standard KDE icon lookup path.
