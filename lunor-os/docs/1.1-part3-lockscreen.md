# LUNOR OS 1.1 — Part 3: Lock screen

Status: implemented.

## Goal

Give the Plasma lock screen a LUNOR identity without replacing KDE's authentication stack.

## What changes

- Dedicated Midnight Black / Deep Navy lock-screen wallpaper.
- Soft Aurora Blue light structure matching boot and SDDM.
- LUNOR Fold mark positioned above the authentication area.
- A default LUNOR Fold user avatar is prepared for newly created users.
- Plasma's stock lock-screen authentication remains intact for reliability.

## Configuration

Both system defaults and new-user defaults point KScreenLocker to:

`file:///usr/share/wallpapers/LUNOR/lockscreen.png`

using the standard `org.kde.image` wallpaper plugin.

This keeps password/PAM handling with KDE while branding the visual layer.
