# LUNOR OS 1.1 — Installer repair

The first real VM test of LUNOR OS 1.0 showed that the live system booted correctly and Calamares opened, but installation stalled after entering the execution phase.

## Root cause addressed

The LUNOR desktop shortcut launched Calamares directly with:

`pkexec calamares`

Debian's live-media Calamares package provides its own wrapper:

`/usr/bin/calamares-install-debian`

That wrapper performs live-media preparation before launching Calamares, including moving the stale live-build `/etc/fstab` out of the way. LUNOR 1.1 now calls the Debian wrapper instead of bypassing it.

## Additional fixes

- Disable Debian's automatic “Install Debian” desktop icon.
- Keep only the LUNOR installer shortcut.
- Replace Debian Calamares branding with LUNOR OS 1.1 branding.
- Keep Debian's tested Calamares module sequence intact.
