# LUNOR OS 1.2 — Desktop Shell

Status: implemented in source.

## Desktop structure

LUNOR OS 1.2 introduces the first recognisable LUNOR desktop layout on top of KDE Plasma:

- **Top status strip** — 32 px, translucent, LUNOR launcher at the left, system tray and date/time at the right.
- **Left quick shelf** — centered floating vertical shelf for workspace controls.
- **Bottom-center launcher** — floating icons-only task launcher with Dolphin, browser, Konsole and System Settings pinned by default.
- **LUNOR wallpaper** — retained as the desktop background.

The layout uses Plasma's supported scripting API instead of replacing Plasma Shell. This keeps the desktop stable while giving LUNOR a distinct structure.

## Design intent

The 1.2 desktop follows the LUNOR language: Clean · Calm · Futuristic · Premium. It deliberately avoids cloning Windows or macOS.

Custom iconography, deeper window styling and motion tuning remain 1.3 work.
