# LUNOR OS 1.1 — Part 2: Login screen

Status: implemented.

## Purpose

Replace the stock SDDM appearance with a coherent LUNOR login experience while keeping SDDM itself for stability.

## Experience

- Midnight Black / Deep Navy background.
- Soft Aurora Blue light structure.
- LUNOR Fold mark centered above the sign-in form.
- Minimal username and password fields.
- Session chooser only appears when more than one session exists.
- Restart and power-off controls remain available.
- Time/date are shown quietly above the form.
- Login failures are surfaced inline without exposing technical details.

## Activation

SDDM is configured through `/etc/sddm.conf.d/20-lunor-theme.conf` with `Current=lunor`.

Theme path: `/usr/share/sddm/themes/lunor/`.
