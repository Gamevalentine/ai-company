# SEO-01 Workflow

OWNER GOAL
    ↓
CEO ATLAS ASSIGNS SEO-01
    ↓
1. Define site/page/market + success metric
    ↓
2. Collect baseline evidence
    ↓
3. Audit technical SEO + on-page + content/search intent
    ↓
4. Prioritize Critical / High / Medium / Low
    ↓
5. Implement authorized SEO-only changes
    ↓
6. Hand source/performance changes to CODE-01 / PERF-01 when needed
    ↓
7. Validate metadata, crawlability, schema, links and build
    ↓
8. Commit/push only when authorized
    ↓
9. Production deploy only with Owner-approved authority
    ↓
10. Verify live result / Search Console evidence when available
    ↓
11. Report evidence + next actions

## Completion gate
A task is complete only when results are verified or the exact verification limitation is reported. SEO-01 must never present estimated rankings, fabricated traffic, or unverified indexing as fact.
